## 2024-03-24 - Accessibility Localization and Cognitive Indicators
**Learning:** For single-language applications (like this Russian portfolio site), relying on default English ARIA labels (e.g., from Bootstrap components like "Close" or "Toggle navigation") creates a disjointed experience for screen reader users whose software is set to read the application's primary language. Additionally, complementing HTML5 `required` attributes with explicit visual indicators (like an asterisk with `aria-hidden="true"`) significantly improves cognitive accessibility without causing redundant screen reader announcements.
**Action:** When adding or updating components in a localized application, always ensure ARIA attributes are translated to match the application's language. Use visual indicators for required fields with `aria-hidden="true"` to aid cognitive accessibility.
