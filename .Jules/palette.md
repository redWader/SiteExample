## 2026-06-11 - Localize ARIA Labels
**Learning:** Boilerplate HTML snippets (like Bootstrap navigation or alerts) often come with English ARIA labels (e.g., aria-label="Toggle navigation"). These create a confusing experience for screen reader users when the document language is different (e.g., lang="ru").
**Action:** Always check and translate ARIA attributes in third-party snippets to match the document's primary language.
