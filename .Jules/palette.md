## 2024-07-05 - Visual indicators for required form fields
**Learning:** While HTML5 `required` attributes are accessible to screen readers, adding explicit visual indicators (like asterisks with `aria-hidden="true"`) improves cognitive accessibility for all users without causing redundant screen reader announcements.
**Action:** Always complement HTML5 `required` attributes with explicit visual indicators when building forms, ensuring the visual indicator is hidden from assistive technologies using `aria-hidden="true"`.
